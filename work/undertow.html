    Undertow Records

    Client
    Undertow Records
    Scope
    Posters, sleeves
    Year
    2024

    Undertow releases run small and ship fast, so the poster series needed a system one person could produce overnight. Each release gets a fixed grid, a single risograph colorway, and a title treatment built from the same six letterforms, stretched and cut differently per record.

    How it came together

    01

    Concept sketches

    Six letterforms, cut and stretched by hand to find a title treatment that could flex per release without losing its identity.

    02

    Risograph test prints

    Each colorway was test-printed on the actual riso stock before being locked into the release grid.

    03

    Final run

    The finished system, ready for a label that needed to turn a release around in a weekend.
